**Please add any progress you have made and note areas that require further improvement or changes in the code.**

### 1. Registration Functionality
- **Password Rules:** The registration process currently enforces the following password criteria:
  - Minimum length of **8 characters**
  - At least **one uppercase letter**
  - At least **one digit**
  - At least **one special character**
  
- **Email Validation:** The registration process includes email format validation to ensure user input meets standard email conventions.

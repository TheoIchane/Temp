# FORUM

***Organisation des fichiers:***

- Data: Databases

- Server: Server code, to run Forum

- Config: Environment variables like api keys

- Middleware: Code for authentication, logging, registering, ect..

- Static: css, javascript, images et autre...

- templates: html pages

- tests: Des fichiers tests et scripts

- Gitignore pour des fichiers que on ne veut pas mettre sur github
